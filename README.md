# Prince of Hesperia

A high-end stylized 2.5D sci-fi reimagining of the classic *Prince of Persia*, set on a dying Mars colony in the Hesperia region.

**Built with**: Three.js + TypeScript + Vite  
**Target**: Modern browsers (especially mobile Safari for virality)

## Current Status

Early foundation stage. 2.5D side-view camera and basic movement in progress.

## Development

```bash
npm install
npm run dev
```

## Goals

- Stay true to the deliberate, weighty, timing-based DNA of the original Prince of Persia
- High-end stylized visuals that feel modern and premium
- Excellent experience on mobile Safari
- Single-player focused experience with strong atmosphere and narrative

## Original Source

Original Prince of Persia (Apple II, 1989) source is included in `original-source/` for reference.

## Branding

This is a spiritual successor, not a direct port. Set on Mars as part of humanity’s future.
